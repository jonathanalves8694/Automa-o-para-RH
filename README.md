# 🤖 Automação para Processos de RH

Este repositório contém um fluxo de automação desenvolvido para otimizar processos na área de Recursos Humanos.

## 🛠️ Tecnologias Utilizadas
* **n8n:** Plataforma de automação baseada em nós utilizada para orquestrar o fluxo.
* **Google Sheets:** Integração com planilhas para leitura e armazenamento de dados dos candidatos.

## 📋 Sobre o Projeto
O arquivo `Simulador RH.json` representa o esqueleto da automação. Ele foi estruturado para conectar a área do candidato com o processo seletivo de forma dinâmica, eliminando tarefas repetitivas e manuais.
